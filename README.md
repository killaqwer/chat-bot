# Бот для чата — запуск

1. **Создать бота:** в Telegram открыть @BotFather → `/newbot` → придумать имя → получить токен.
2. **Ключ нейросети** (чтобы бот отличал полезное от флуда): зарегаться на console.groq.com → API Keys → создать ключ.
3. **Настроить:** переименовать `.env.example` в `.env`, вписать `BOT_TOKEN` и `LLM_API_KEY`.
4. **Запустить:** нужен Python 3.10+
   ```
   pip install -r requirements.txt
   python bot.py
   ```
5. **Подключить к чату:** добавить бота в группу → сделать админом с правами
   «Удалять сообщения» и «Закреплять сообщения».
6. Написать в чате `/chatid`, себе в личку боту `/myid` → вписать эти id в `.env`
   (`GROUP_IDS`, `ADMIN_IDS`) и перезапустить бота.

Бот работает, пока запущен `python bot.py`. Выключил комп — бот спит.
Для 24/7 нужен сервер (VPS).

## Команды
В чате (ответом на сообщение): `/keep` — не удалять, `/pin Папка/Подпапка` — закрепить и сохранить,
`/save Папка/Подпапка` — только сохранить, `/check` — проверить чат сейчас.

В личке у бота: `/base` — база с папками. Кидаешь туда текст/файл — сохраняется в открытую папку.
Кнопки: ➕ папка, 🗑 удалить папку/запись.

Всё хранится в файле `bot.db` рядом с ботом — его не удаляйте, это ваша база.
